# ⚡ Next-Gen Toolbox (多功能赛博朋克工具箱)

这是一个基于 Python 和 Streamlit 开发的在线多功能工具箱。

## 🔗 在线体验 (Live Demo)
👉 **[点击这里访问我的应用](https://wgx065-engine.streamlit.app)**

## 🛠️ 功能列表
- 📝 **文本分析器**：分析字符长度、检测关键词、文字反转。
- 🔐 **随机密码生成器**：自定义长度和字符类型，生成高强度密码。
- 📁 **批量文件重命名**：批量修改文件名并打包为 ZIP 下载。
- 📊 **Excel 数据清洗器**：一键删除表格中的空行和重复项。

## 🚀 技术栈
- Python
- Streamlit
- Pandas
